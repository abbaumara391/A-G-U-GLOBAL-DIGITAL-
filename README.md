## DEPLOYMENT

To publish the frontend using GitHub Pages:

1. Open repository Settings.
2. Open Pages.
3. Select Deploy from a branch.
4. Select the main branch.
5. Select the root folder.
6. Save.

Wait for GitHub Pages to publish the website.

---

## SUPABASE CONFIGURATION

Open Supabase:

Authentication → URL Configuration

Configure:

- Site URL
- Redirect URLs

Add your published GitHub Pages address.

Test registration, email confirmation and login.

---

## SECURITY

The Supabase publishable key is intended for browser use.

NEVER expose:

- Supabase service-role keys
- Database passwords
- Secret API keys
- Payment provider credentials
- Private cryptocurrency keys

All financial operations must use trusted server-side functions.

Wallet credits and debits must be validated through secure ledger operations.

Customer deposits must not be accepted until the payment infrastructure, security controls and applicable legal requirements have been completed.
